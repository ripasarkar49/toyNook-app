## Project Name:

ToyNook => Kids Toy Marketplace

## Purpose:

A modern web application built using **React + Firebase** where users can browse toys, view details, register/login, and manage their accounts. This project also includes authentication, protected routes, password reset, Google login, and a mobile-responsive UI.

- Browse toys with details
- Create accounts using email/password
- Login using Google Authentication
- Reset password via email
- See their profile image in Navbar after login
- Navigate across different pages (Home/Toys/Login/Register)
- Mobile responsive navigation (drawer menu)

## Live Link: toynook.netlify.app

## Key Features

1. Authentication ==> Email & Password (Login & Registration)
2. Firebase Auth ==> Login, Logout, Google Sign-in
3. Protected Routes ==> Some pages are only accessible after login
4. Password Reset ==> Firebase password reset email feature
5. Mobile Responsive ==> Drawer Menu + Responsive Layout
6. Profile Image ==> User photo & display name on navbar
7. 404 Page ==> Custom Not Found Page
8. SweetAlert2 ==> Toast alerts & notifications
9. Loading Spinner ==> While checking auth state
10. Context API ==> Global user authentication context

## NPM Packages Used

a. firebase ------- Authentication & database
b. react-router ------- Routing & navigation
c. sweetalert2 ------- Alerts and notifications
d. react-icons ------- Icons for UI
e. daisyui ------- Pre-styled components
f. tailwindcss ------- Styling and responsiveness
g. react ------- Core library
h. Swiper slider
